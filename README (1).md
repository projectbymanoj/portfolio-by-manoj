## How this site is hosted

This repo is deployed with **GitHub Pages** directly from the `main` branch.

Repo name: `vmano3467-a11y.github.io`
Because the repo name matches `<username>.github.io`, GitHub automatically
publishes it at `https://vmano3467-a11y.github.io/` — no extra config needed.

## Updating the live site

1. Replace `index.html` in the root of this repo with the new version.
2. Commit and push to the `main` branch:
   ```
   git add index.html
   git commit -m "Update portfolio"
   git push
   ```
3. GitHub Pages rebuilds automatically. Changes usually go live within
   1–2 minutes. Hard refresh (Ctrl/Cmd + Shift + R) if you don't see updates
   right away — browsers cache aggressively.

## First-time setup (if starting fresh)

1. Create a GitHub repo named exactly `vmano3467-a11y.github.io`.
2. Add `index.html` to the root of the repo.
3. Go to **Settings → Pages** in the repo.
4. Under **Build and deployment → Source**, select **Deploy from a branch**.
5. Set **Branch** to `main` and folder to `/ (root)`, then **Save**.
6. Visit `https://vmano3467-a11y.github.io/` after a minute.
